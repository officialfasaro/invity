Arsitektur & Gambaran Umum Database
Overview

1. Core Architecture

PostgreSQL & Prisma ORM
  • RDBMS Utama: Menggunakan PostgreSQL dengan relasi foreign key dan aturan cascade delete yang teruji.
  • Type-safe ORM: Prisma menyediakan auto-generated client TypeScript dengan nol toleransi tipe 'any'.
  • CUID Identifiers: Seluruh Primary Key mengadopsi standar CUID yang anti-collision dan aman dari ID enumeration.
  • Multi-tenant Model: Satu user dapat memiliki beberapa undangan dan mengelola mutasi transaksi secara independen.

2. Klasterisasi Domain

11 Tabel dalam 4 Modul
  • Modul Akun & Auth: users untuk mengelola kredensial dan hak akses (USER/ADMIN).
  • Modul Undangan Inti: invitations sebagai pusat data pengantin, link slug, dan konfigurasi tema.
  • Modul Fitur Resepsi: event_schedules, galleries, bank_accounts, guests, rsvps, wishes.
  • Modul Transaksi & Sistem: payment_transactions, theme_catalogs, system_settings.

3. Kebijakan Integritas

Keamanan & Audit Trail
  • Cascade Delete: Penghapusan undangan otomatis membersihkan jadwal, galeri, buku tamu, RSVP, dan doa restu.
  • SetNull Policy: Transaksi pembayaran tetap disimpan meski undangan dihapus untuk audit finansial akuntansi.
  • Composite Constraint: guests(invitationId, slugCode) menjamin tautan nama tamu tidak saling tumpang tindih.
  • Enums Terstandar: UserRole, SubscriptionTier, PaymentType, PaymentStatus.

Spesifikasi Tabel
Tabel users — Pengelolaan Akun & Otorisasi
AUTH & ACCOUNT

Menyimpan identitas akun pengguna (calon pengantin dan administrator sistem). Mengatur autentikasi JWT, password hashing via Bcrypt, dan hak akses Role-Based Access Control (RBAC).

Nama FieldTipe DataConstraintKeterangan / Fungsi
idString (cuid)PKID unik primary key akun
emailStringUNIQUEAlamat surel untuk login pengguna
passwordHashStringNOT NULLHash kata sandi aman via Bcrypt
nameStringNOT NULLNama lengkap pengguna / mempelai
roleUserRoledef: USERHak akses: USER atau ADMIN
createdAtDateTimeNOW()Timestamp akun didaftarkan
updatedAtDateTimeUPDATED_ATTimestamp profil terakhir diperbarui

Relasi Antar Tabel

  • 1 : N ke invitations: Seorang user dapat membuat beberapa proyek undangan pernikahan.
  • 1 : N ke payment_transactions: Mencatat riwayat pembelian langganan paket.
  • OnDelete: Cascade: Penghapusan user otomatis menghapus undangan miliknya.

Aturan Bisnis

  • Validasi input menggunakan Zod Schema di boundary controller.
  • Password wajib melalui proses hashing sebelum disimpan ke database.
  • Role ADMIN memiliki akses ke dashboard verifikasi transaksi manual.

Composite Constraint

Buku Tamu Digital

  • Mendukung ekspor daftar kehadiran tamu ke Excel / CSV untuk evaluasi WO.

1. Keamanan & Performa

Best Practices Database
  • Indexing Efisien: Indeks unik pada email, slug, dan orderId menjamin kecepatan respon lookup sub-millisecond O(log N).
  • SQL Injection Shield: Prisma ORM melindungi semua query via parameterized prepared statements secara otomatis.
  • Sanitasi XSS: Input teks ucapan doa dan data JSON selalu divalidasi dan disanitasi dari script injeksi.
